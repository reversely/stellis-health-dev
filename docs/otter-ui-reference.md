Design notes: Preserve a large readable conversation title, compact metadata, clear Summary/Transcript tabs, and a persistent playback control near the transcript. The user's preference is for Otter's import/record button prominence, font sizes, hierarchy, speaker rematch, and labels. Language choice must reflect models actually installed on the device; an English-only whisper model must not claim multilingual support. AI outputs need transcript citations and must reflect edits and corrected speakers when regenerated.

## Transcript navigation and edit mode, observed 2026-10-16

In the signed-in CIFAR interview, Otter displays speaker turns as text bubbles with a speaker label and timestamp. Normal transcript words are individual `transcript-word` spans carrying timing attributes; clicking a bubble/word navigates playback, while a fixed bottom player provides seeking and transport. The transcript header has one **Edit transcript** action. Activating it changes that control to **Done**, exposes undo/redo, and makes the transcript editable. The same page was observed via REA CDP target evidence `ev_6a786392add5fdad9aa4c1d8d8ca7523ecec36aa3c7248853f266d92fbe27238`; the edit-mode screenshot was inspected in the signed-in Chromium session. These are observed browser behaviors, not a claim about Otter’s internal storage model.

Stellis implements the global mode and segment-start seeking in #45. Exact measured word timing and word-level seeking remain #39.

## Speaker rematch, observed 2026-10-16

On the signed-in conversation, **Rematch speakers** is in the conversation's top **More options** menu, beside actions such as language change and text/audio sync. Selecting it immediately submitted a request; no confirmation dialog or speaker-selection form appeared. A toast said the auto-tag request was accepted and to check back in 10–15 minutes. The transcript stayed visible with its normal speaker labels and playback controls. This entry and request state were observed with REA browser target evidence `ev_5f16389173b5d1d26bb4f2f8488d025e27fc41f57b14ba6a3a119880a6afbd85` and screenshot evidence `ev_8512abed128528cd80867f4bdca820c51499b31f80f3d98baa20c2e6fb6bab49`.

Completion, failure, retry, and preservation of manually assigned names have not yet been observed in Otter. Those behaviors must be checked after the requested run completes; do not infer them from the toast.

After more than 25 minutes, a reload still showed the same six anonymous speaker groups and the same initial turn labels. No rematch progress, completion, or failure message was visible. REA screenshot evidence `ev_cb74c6a5296878ba36622720c3c70249bb7c96e363b3f89c49f788638ac54f58` records that later state. The unchanged labels do not show whether Otter finished and made no changes or whether its request was still pending; that result remains unknown. No named speaker was changed in the user's Otter account for this observation.

A later signed-in reload still exposed the interview and its transcript, with no rematch completion state surfaced in the conversation header. The account did not provide enough evidence to classify the prior request as succeeded or failed. Stellis therefore shows its own persisted job state and leaves automatic assignments distinct from confirmed Person names.

## Reference audit: speaker tags, playback, and recording, observed 2026-10-16

**Named references inspected separately:** `docs/refs/labelspeaker.png` shows an unnamed speaker's picker with Search speakers, a disabled Tag button when empty, an existing-speaker row, and Manage Speakers. Its tutorial overlay is transient. `docs/refs/labelspeaker2.png` shows the same picker with a new name typed, no matching row, and Tag enabled. `docs/refs/recordinginprogress.png` shows the live recording workspace: a Note title, owner and time, Transcript area, persistent bottom recorder with source/language, Pause, elapsed time, Stop, and a right AI Chat panel with suggested prompts. This screenshot establishes layout and visible controls, not recording reliability.

**Live signed-in account inspected:** Clicking an unnamed **Speaker 2** label and clicking the named **Jay Matlock** label open the same compact tag dialog. It lists existing speakers; the named label's row exposes Untag. Manage Speakers opens a separate modal with search, a speaker list, rename/hide controls, and selection for merge. This was observed in the Chromium Otter tab on the user's CIFAR interview. The per-label picker is a normal transcript action; it does not enter Edit transcript mode. Ticket #83 tracks Stellis's mismatch.

The same live transcript has timed word spans inside clickable text bubbles and a fixed bottom player. The visible player includes a segmented scrub bar, skip back/forward by five seconds, Play, speed, and elapsed/total time. A physical drag across six words opened a small toolbar above the selection with **Highlight, Comment, Add Image, Copy, Share** in that order. Synthetic DOM selection alone did not open it; the pointer action mattered. Clicking a timed word whose `data-word` began at 78.96 seconds moved the seek slider to 79 seconds. With the slider focused, ArrowRight advanced its reported position from 86 to 96 seconds. Clicking Edit transcript changed it to Done and set the text bubbles to `contenteditable="plaintext-only"`; clicking Done restored read mode. These are live interaction observations, not storage claims. The existing #18 acceptance issue covers the real-interview browser workflow; #84 tracks the remaining reference comparisons.

**Live Import and Record:** Otter's home bar shows Import and Record side by side. Import opens a centered **Transcribe audio and video** modal with Drag & Drop, Browse files, supported audio/video formats, transcript language selection, and an import allowance. Record opened a new Note in the *same* tab, with a left Transcript area, a fixed bottom recorder showing microphone source, English, Pause, elapsed time, and Stop, and a right AI Chat panel. Pausing changed Pause to Resume while Stop remained available; Resume returned the recording state. Stop returned to Home and left a 14-second Note in the list. The investigation deleted that disposable Note through More options → Delete and verified it was absent from Home, then restored the CIFAR reference tab. This confirms the visible control flow and a short recording; longer capture reliability is a separate acceptance check. The supplied `recordinginprogress.png` matches this live layout.

**Manage Speakers detail:** The live Otter modal exposed a Search field, a checkbox beside Jay Matlock, separate rename and hide buttons, and a disabled Merge action until speakers are selected. Clicking rename replaced Jay's name with an inline field prefilled **Jay Matlock** and a Cancel action; no change was saved. Stellis #85 now uses a separate searchable modal for these Person actions, keeps manual names from the current recording visible as local labels, and retains the detailed passage editor behind Edit this passage. The real interview and a two-Person disposable browser fixture checked the modal, rename, hide/show, merge target choice, a confirmed merge, and 390-pixel layout.
