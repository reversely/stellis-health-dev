## Observations and design inference

These are observations of the screenshots. They do not establish behaviour.

- **Contrast is underused.** Most surfaces are pale on pale. Existing colour blocks (the selected tab, primary buttons, the selected citation chip, the call avatar) carry inverted text, and new work keeps that. Light mode uses a dark block with light text; dark mode flips to a light block with dark text instead of making everything dark. Use the `--action-*` and inverted roles in `theme.css`.
- **Prototype controls are not product controls.** *Prototype state*, *Prototype date* and *Prototype: step through the call* switch mock states. The product derives these states from real data and time.
- **All content is data.** Names, values, dates, medicines and labels come from records, accepted facts, the tracker registry and traces. Nothing in these images is to be copied into code as a literal.
