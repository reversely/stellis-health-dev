# Stellis user guide

This guide covers every screen and shortcut in Stellis. Each page names the buttons as they appear in the app.

- [Getting started](getting-started.md): start Stellis, create the account, add a Nebius key, load the sample workspace, and take the tour.
- [Interface](interface.md): the sidebar, Home, collections, notebooks, notes, meetings, to-dos, suggestions, Recently Deleted, export, and search.
- [Keyboard and Markdown shortcuts](shortcuts.md): one table of typed Markdown, key combinations, and menus.
- [Privacy](privacy.md): what stays on your computer and what leaves it.
