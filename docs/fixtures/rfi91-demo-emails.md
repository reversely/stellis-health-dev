# RFI 91 synthetic emails for the demo

These messages are fictional. Send each message to the Google account connected to Stellis, in the order shown. Use the subject exactly so Gmail groups them into one thread if possible. The "Role" line is part of the body; your actual sender address will remain your own. Do not copy these to real project contacts.

The sample workspace in Stellis already contains a matching Water Treatment notebook, meeting, specification, status page, and three simulated mailbox messages. These emails add real Gmail API evidence for the same case. The facts below deliberately leave engineer approval unresolved.

Sample project email. Please prepare a draft response for review. State that the revised schedule and C316 traceability are under engineering review. ## Expected answer boundaries

- Opened September 28, 2026.
- Revised schedule and a traceable material certificate are required.

This follows the RFI pattern of request, review, official response, and closure described in [Autodesk's RFI workflow](https://help.autodesk.com/cloudhelp/ENU/Build-Rfis/files/work-rfis/Process_RFI.html). The fictional case facts come from [the fixture answer key](rfi91-answer-key.md).
